<h1> to <h6>

Defines 6 levels of headings. <h1> is the largest and most important main heading on the page. From <h1> to <h6>, the headings decrease in size.

<p> Paragraph

Defines a paragraph of regular body text. Browsers automatically add top and bottom spacing around paragraphs.

Paired Containers

Both are paired tags requiring an opening tag (e.g., <p>) and a closing tag (e.g., </p>).

<a> Anchor Tag

Used to create hyperlinks. It is a paired container tag that requires a closing </a> tag.

href="..." Attribute

Stands for Hypertext Reference. Specifies the target web address or URL destination of the link.

target="_blank"

Instructs the browser to open the target webpage in a brand new browser tab or window. [Note: not a problem if not used]

title="..." Attribute

Displays extra descriptive text as a floating desktop tooltip when hovering mouse cursor over the link.[Note: not a problem if not used]
